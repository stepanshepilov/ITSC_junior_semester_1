# Практика

## Задача
Реализовать функции `minimum`, `maximum`, `mean`, `median` и `frequency_table` для списка чисел.

## Вход
Список чисел Python, включая отдельные случаи: пустой список, один элемент, повторяющиеся значения.

## Выход
Каждая функция возвращает результат; для пустого списка решение должно быть явно описано: исключение или специальное значение.

## Git-часть
Создать ветку `statistics`, сделать минимум три осмысленных коммита: каркас, реализация, исправление/тесты. Слить ветку после проверки.

## Артефакт
`statistics.py`, примеры запуска и `README.md` с решениями для трех тестовых наборов.

## Проверка
Сравнить результаты с ручным расчетом или стандартными функциями там, где это уместно. Описать одну найденную ошибку.
