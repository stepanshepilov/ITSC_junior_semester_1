# Теория

## Коллекции и циклы
Список хранит упорядоченные значения, словарь связывает ключи со значениями. `for` применяет действие к каждому элементу, а `while` повторяет его, пока истинно условие. Для статистики важно корректно обработать пустой список.

## Функции
Функция получает аргументы и возвращает результат. Хорошая функция делает одну понятную вещь и не зависит от глобальных переменных. Это облегчает проверку и повторное использование.

## Отладка
Разделяйте ошибку на маленький пример, проверяйте типы и промежуточные значения. Тестовый пример должен показывать ожидаемый результат, а не только факт запуска.

## Git
Рабочая директория содержит текущие изменения, staging area — подготовленные изменения, commit — снимок истории. Минимальный цикл: `git status` → `git add` → `git commit`. Ветка позволяет работать над изменением отдельно.

## Связь с ML
Данные часто представлены списками и таблицами, а повторяемые вычисления удобно оформлять функциями. Git нужен, чтобы сравнивать эксперименты и возвращаться к рабочему состоянию.
