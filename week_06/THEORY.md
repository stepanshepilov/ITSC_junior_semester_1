# Теория

## Виды обучения
В supervised learning есть признаки `X` и известная цель `y`. В regression цель числовая, в classification — класс. В unsupervised learning целевой переменной нет; пример — кластеризация.

## Разбиение
Train используется для обучения, validation — для выбора подхода, test — для финальной независимой оценки. При небольших данных можно использовать кросс-валидацию.

## Baseline
Baseline — простое правило, с которым сравнивается модель: среднее значение для регрессии или самый частый класс для классификации. Модель имеет смысл только если дает улучшение, которое подтверждается метрикой.

## Утечка
Утечка возникает, когда в признаки попадает информация, недоступная в момент предсказания, или информация из test влияет на обучение. Это делает оценку слишком оптимистичной.
