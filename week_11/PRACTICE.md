# Практика

## Задача
Сгруппировать объекты без использования target и подготовить промежуточный проект.

## Вход
Набор данных с несколькими числовыми признаками и краткое описание предметной области.

## Что сделать
- выбрать признаки и обосновать масштабирование;
- обучить k-means для нескольких `k`;
- визуализировать кластеры напрямую или через PCA;
- оценить устойчивость и предметный смысл групп;
- оформить мини-проект по схеме вопрос → данные → метод → результат → ограничения.

## Выход
`clustering_project.ipynb` и устная защита на 3–5 минут.

## Проверка
Отдельно указать, использовался ли target только для анализа после кластеризации.
