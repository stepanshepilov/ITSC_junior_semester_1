# Теория

## 1. Программа и алгоритм
Алгоритм — конечная последовательность точных шагов, которая преобразует вход в выход. Перед кодом полезно записать пример входа, ожидаемый результат и несколько шагов решения.

## 2. Базовый Python
Переменная хранит ссылку на значение. На старте достаточно типов `int`, `float`, `str` и `bool`. Условия позволяют выбрать ветку выполнения:

```python
if score >= 60:
    result = "pass"
else:
    result = "retry"
```

Ввод из `input()` всегда приходит строкой, поэтому число нужно преобразовать через `int()` или `float()`.

## 3. Ошибки
Syntax error означает, что Python не понял структуру программы. Runtime error возникает во время выполнения. Логическая ошибка дает неправильный результат без падения программы. Читаем traceback снизу вверх и проверяем значения небольшими `print()`.

## 4. Связь с ML
Любая модель машинного обучения тоже принимает вход и возвращает выход. Пока мы не обсуждаем обучение, но уже учимся разделять данные, преобразование и результат.

## Минимум
Уметь написать условие, преобразовать строку в число и проверить программу на нормальном и пограничном входе.
